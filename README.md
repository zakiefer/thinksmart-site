Think Smart Public Adjusting — marketing site.

Static site (Claude Design export). Leads from the claim form, the message form and the chat go to
the site's own `send-lead.php`, which saves each one in the private folder beside the web root first
and then emails it; the website editor at `/edit` shows them for 90 days. The pages themselves are
built by the editor from templates and one content file: see `edit/README.md`.
